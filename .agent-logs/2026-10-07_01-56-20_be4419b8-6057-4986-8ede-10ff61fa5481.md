**How it works now**
- **Server:** one Cloudflare Worker serves both the site and `/api/*`. Each generation is re-priced on the server, charged in a single database transaction, then run as a Workflow job:
  1. Wait for a free slot under the plan's concurrency limit.
  2. Submit to the vendor.
  3. Poll until the result is ready.
  4. Copy the output into R2 storage.
  5. Mark the job done, or failed and refunded.
- **Vendors:** I wrote adapters for Kling 3.0 and 2.6, Veo 3.1, Nano Banana 2.1, Seedance 2.0 and 2.5, and Wan 2.7. A model whose vendor key is missing still goes through the server and is billed, but returns a sample clip. The model picker labels those models "Demo output".
- **Browser:** when the backend is on, credits and the job queue are loaded from the server and checked every 3 seconds. Progress animates in between and stops at 95% until the server says the job is done. Uploaded references go to R2.
- **Payments:** the pricing page and paywall open Stripe Checkout. A webhook adds plan credits on each paid invoice and pack credits when checkout completes, and never applies the same payment twice. Subscribers get a "Manage billing" link to the Stripe portal.

**To turn it on**, follow the "Live mode" section of `README.md`:
1. Run `supabase/migrations/0001_billing.sql` in Supabase.
2. Create the R2 bucket.
3. Set `SUPABASE_URL` and the secrets.
4. Add the Stripe prices and the webhook.

For local work, `pnpm dev:worker` runs the API on port 8787 alongside `pnpm dev`.

**Risks to watch on first real runs:**
- **Wan with a start frame:** I assumed the image-to-video model id is `wan2.7-i2v`, built from the documented text-to-video id. Wan also downloads frames from a public URL, so testing it locally needs a tunnel.

- **Unlimited plans:** jobs on live models are capped at 30 per day per user. After that they're charged normally, so the Generate button can show "Unlimited" while the server actually charges.
- **Video thumbnails:** vendors don't return posters, so cards show the video's first frame instead.
